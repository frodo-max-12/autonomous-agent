autonomous-agent

One process that runs the whole quote cycle for a semiconductor distributor — inquiry in, vendor sourcing, lowest-cost consolidation, margin, and a confidence-gated quote back out. Humans only touch what the gate holds.
the rule: the model judges, the code computes. no price, FX rate or duty is ever invented — if a number is missing the line is blocked, never auto-sent.

After the quote

negotiation, orders, and the learning that feeds back into routing

A target price is met by trimming margin to the floor, or by re-asking vendors for a capped % off their own cost · the customer's target never leaks

The human's whole job

  • Open the dashboard. Finish the lines the gate held, with the reason already on screen.
  • Add or rank vendors. Close deals as won, lost or silent so the scorecard learns.
  • Flip AGENT_MODE from testing to automatic when the drafts look right.
